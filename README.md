# Проєкт: Застосунок "Список покупок"

## Доданий функціонал:
1) Змінив відображення кнопки додавання
2) Додав кнопку видалення
3) Додав можливість редагування 
4) Додав відображення кількості куплених товарів
5) Простий декор для тексту, якщо об'єкт придбано

## Труднощі:
1) Невеликі труднощі у розумінні приниципу взаємодії бази даних з ViewModel.
2) Через непердбачувані обставини, мій комп'ютер вимкнувся під час компіляції програми, що призвело до пошкодження кешу gradle, через що код просто не виконувася. Повне видалення кешу gradle та його перевстановлення вирішило проблему.
3) Спроби додати pull-to-refresh не були успішні, використання залежності "androidx.swiperefreshlayout:swiperefreshlayout:1.1.0" дало змогу додати анімацію, але імплементувати повноцінного оновлення не вдалося, тому від цього покращення відмовився.
